# E-Commerce Sales Analysis

## Project Overview
This project focuses on analyzing an E-Commerce sales dataset using Python. The main objective is to understand sales performance, customer behavior, product performance, and revenue trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Details
The project uses three datasets:

- **Products:** Product ID, Product Name, Category, Price
- **Customers:** Customer ID, Customer Name, City
- **Orders:** Order ID, Customer ID, Product ID, Quantity, Order Date

## Data Analysis Performed
- Data loading and preprocessing
- Missing value checking
- Duplicate value checking
- Data type conversion
- Merging datasets
- Revenue calculation
- Best-selling product analysis
- Category-wise revenue analysis
- Customer-wise sales analysis
- City-wise sales analysis
- Monthly revenue trend analysis
- Data visualization
- Business insights generation

## Key Findings
- **Total Revenue:** 459300
- **Best-Selling Products:** Cap and Mouse
- **Top Revenue Category:** Electronics
- **Top Customer ID:** C101

## Visualizations
- Monthly Sales Revenue
- City-wise Sales Revenue
- Category-wise Revenue Distribution
- Sales Correlation Heatmap
- Top 5 Best-Selling Products
- Top 5 Customers by Revenue

## Project Files
- `main.py` – Python analysis code
- `products.csv` – Product dataset
- `customers.csv` – Customer dataset
- `orders.csv` – Orders dataset
- `analyzed_sales.csv` – Analyzed sales data
- `business_insights.txt` – Business insights report

## Conclusion
This project helped analyze E-Commerce sales data and identify important business insights using Python and data visualization techniques.
